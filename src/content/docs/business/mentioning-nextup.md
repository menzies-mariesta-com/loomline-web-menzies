# Mentioning NextUp

When you write about the product for guests, staff, or partners, keep the name simple and point people to the official site.

## Name

- Use **NextUp** as the product name.
- Use **NextUp QMS** only when you need to say it is a queue system.
- Soft Wash is the calm look of the screens, not a second product name.

## Helpful links

Share these from your NextUp site (ask your admin for the exact web address if you are unsure):

| What | Where |
|------|-------|
| Product home | `/` |
| Pricing | `/pricing` |
| Help docs | `/docs` |
| Sign in | `/auth/login` |

## Short credit

If a partner page needs a one-line credit:

> Powered by NextUp.

For logos, Soft Wash colors, and full website reference details, open **Branding** on the docs hub, or go straight to [Brand guidelines](/docs/brand/overview) and [How to reference NextUp](/docs/brand/referencing).
