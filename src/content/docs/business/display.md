# Display TV

Open the TV from **Devices** with **Open TV**, or load the display link for that pairing code on the waiting-room screen.

## What guests see

- Header: business logo and name on the left, department on the right, fullscreen control.
- Left: **Now serving** with large ticket numbers.
- Right top: **Upcoming** waiting tickets.
- Right bottom: **Missed** (no-shows for today).

Click the board (or the fullscreen control) for browser fullscreen. Escape exits.

## Voice

Set voice on **Config**:

1. Add announce languages in the order they should be spoken.
2. Choose how many times to repeat the full language pass.
3. Edit the now-serving announcement text.
4. Save voice.

The display speaks in that language order, then repeats for the frequency you chose. Refresh or keep the screen online so it picks up the latest settings.

> Tip: test voice at normal waiting-room volume before opening day.
