# Floor setup

Do this as an owner or manager before guests arrive. Home may show a **Finish setup** tip until a department exists.

## Setup order

1. **Sites**: add a branch or floor location.
2. **Services**: what guests pick when they take a number (name, optional ticket prefix, priority).
3. **Departments**: group counters under a site (or use **Create General** on Home when offered).
4. **Counters**: attach to a site and department; leave status **open** so staff can call.
5. **Queues**: name + site + service, and how tickets are ordered:
   - First come first served
   - Priority
   - Appointments first
6. **Destinations** (optional): needed if agents will use **Redirect**.
7. **Timelines** (optional): multi-step guest journeys.

## What depends on what

- A department needs a site.
- A counter needs a site and a department.
- A queue needs a site and a service.

Without an open counter and a queue for the service, **Call next** and kiosk take-a-number will not run smoothly.

> Tip: finish Sites → Services → Departments → Counters → Queues before you pair devices.
